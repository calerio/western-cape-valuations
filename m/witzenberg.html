Cape Winelands · General valuation roll · 2023-2027

Witzenberg property valuations

The Witzenberg municipal valuation roll (general valuation roll, 2023-2027) values 16 393 properties in the Cape Winelands district of the Western Cape — median value R154k, R20bn in total.

Witzenberg's last full general valuation was 2013. Since then the municipality has published only supplementary rolls (2018 and 2022 cycles) and a 2023 general roll for Ceres alone — so the 2013 roll is still the most recent set of values covering the whole municipality.

Values are municipal valuations as at the roll's valuation date — the municipal valuer's market value, set for calculating rates. A property can sell for more or less than its roll value today.

How these valuations work

Municipal valuations estimate each property’s open-market value on a set past date (mass appraisal under the Municipal Property Rates Act) — calculated to charge rates, not a floor or a live sale price. How valuations work →
