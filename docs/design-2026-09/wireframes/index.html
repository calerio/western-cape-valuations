A·1 — Explore, first paint (province level)

Callouts

  • ① Headline block: scope line, three figures, two primary actions
  • ② Locator: SA outline + clickable choropleth; navigation, not a gate
  • ③ Data-coverage strip, always visible, “▸ details” opens roll list
  • ④ Municipality table: sortable, share bar, median marker on one scale, first 8 rows
  • ⑤ Log histogram with p10 / median / p90 and two concentration callouts

Solves

  • First screen answers “how much, where, how sure” without clicking the map
  • Two clear routes onward: find a property or open the map
  • Coverage caveats visible up front, not buried in footnotes
  • Municipalities comparable at a glance on shared scales

Interaction changes

  • Choropleth click drills province → district → municipality; stats update in place
  • Table headers sort (⇅); “Show all 25 ▾” expands in place
  • Progressive disclosure: sections beyond ④⑤ collapsed until scrolled into view or opened
  • “How this is computed ▾” per section, closed by default
  • Global search in the top bar replaces the in-map search on this page

Unchanged

  • Hash deep-link #m/<slug> keeps working (opens municipality level)
  • Municipality level uses the same structure: choropleth zooms in, ④ lists towns/suburbs
  • Existing “Who sets & governs these values” and rates blocks stay at municipality level
  • d3 choropleth, EN/AF catalogue, static muni pages

Mobile / Performance

  • Stats from one small explore.json (decision 5), no search DB on this page
  • Search-DB pre-warm deferred to after first paint (decision 4)
  • Collapsed sections render their charts only when opened
  • Mobile layout: see B
